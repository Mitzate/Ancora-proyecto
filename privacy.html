Políticas del sistema Áncora

Responsable del tratamiento de datos

El sistema Áncora, desarrollado como proyecto académico-tecnológico, es responsable del tratamiento de los datos personales que el usuario proporcione al interactuar con la plataforma, el portal web y los dispositivos IoT asociados.

El sistema opera bajo los principios de licitud, consentimiento, información, calidad, finalidad, lealtad, proporcionalidad y responsabilidad conforme a la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP).

Datos que recopilamos

Áncora recopila únicamente los datos necesarios para operar el sistema de monitoreo. Los datos que podemos recabar incluyen:

  • Nombre completo y correo electrónico del usuario registrado
  • Datos de acceso al portal (usuario y contraseña cifrada)
  • Datos generados por los sensores: detección de movimiento, presencia, caídas y distancias
  • Marca de tiempo y localización del dispositivo sensor
  • Dirección IP y tipo de navegador al acceder al portal web
  • Historial de alertas enviadas vía Telegram

Nota importante: Los datos de los sensores (movimiento, caídas, presencia) son exclusivamente operativos. No se comparten con terceros ni se utilizan con fines comerciales o publicitarios.

Uso de los datos

Los datos recopilados se utilizan exclusivamente para las siguientes finalidades:

  • Operar y mantener el sistema de monitoreo inteligente
  • Enviar alertas en tiempo real a los contactos designados vía Telegram
  • Permitir el acceso autenticado al portal de monitoreo
  • Generar reportes históricos de eventos para el usuario
  • Mejorar el funcionamiento y la precisión del sistema
  • Cumplir con obligaciones legales aplicables
Seguridad de la información

Áncora implementa medidas técnicas y organizativas para proteger tus datos:

  • Comunicación cifrada mediante protocolo TLS/SSL entre dispositivos y la nube
  • Autenticación con credenciales protegidas y sesiones seguras
  • Acceso restringido a los datos: solo el usuario autorizado y el equipo técnico pueden acceder a la información
  • Certificados X.509 para autenticación de dispositivos IoT a través de AWS IoT
  • Datos en reposo cifrados mediante AWS KMS (Key Management Service)
Cookies y tecnologías de rastreo

El portal web de Áncora puede utilizar cookies de sesión para mantener activa la autenticación del usuario. No se utilizan cookies de seguimiento comercial ni se comparte información de navegación con redes publicitarias.

El usuario puede configurar su navegador para rechazar cookies, aunque esto puede afectar el funcionamiento del portal.

Transferencia de datos a terceros

Áncora no vende, alquila ni cede datos personales a terceros con fines comerciales. Los únicos supuestos en que puede compartirse información son:

  • Cuando sea requerido por autoridad competente conforme a la ley
  • Con proveedores de infraestructura tecnológica esenciales para la operación del sistema (AWS IoT, Firebase), quienes actúan como procesadores de datos bajo acuerdos de confidencialidad

Google Play Store

Apple App Store

  • Debe ofrecerse la opción de eliminación de datos de forma accesible dentro de la app
  • Cumplimiento obligatorio de los lineamientos de seguridad y privacidad de Apple para publicación
Utilizado en: Apps móviles

Derechos del usuario

Derechos ARCO

Como titular de tus datos personales, tienes derecho a:

  • Acceso: conocer qué datos personales tenemos de ti y cómo los usamos
  • Rectificación: solicitar la corrección de datos inexactos o incompletos
  • Cancelación: solicitar la eliminación de tus datos cuando no sean necesarios
  • Oposición: oponerte al tratamiento de tus datos para finalidades específicas

Para ejercer tus derechos, contacta al equipo Áncora en: ancora.info@gmail.com
