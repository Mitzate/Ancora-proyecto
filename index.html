El proyecto

Descripción
del proyecto

Sistema basado en un sensor inteligente capaz de detectar movimiento, medir distancias y reconocer caídas.

Integrado con microcontroladores ESP32 para enviar alertas en tiempo real vía Telegram, con comunicación LoRa y encriptación TLS.
